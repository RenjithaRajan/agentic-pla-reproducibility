# Results

Outputs reported in the paper.

- `metrics/`: validation, test, and CASF-2016 metrics (RMSE, MAE, Pearson R, Spearman, CI, etc.), baseline comparisons, and bootstrap confidence intervals.
- `predictions/`: per-complex predictions with uncertainty estimates.
- `figures/`: plots used in the manuscript.

Each file is named after the table or figure it supports in the paper.
