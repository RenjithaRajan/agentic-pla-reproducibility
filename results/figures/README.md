# Figures

Figures used in the manuscript. Each file is named after the figure it supports. All figures are generated by the notebook `notebooks/Agentic_PLA_reviewer_revision.ipynb`.

## Main figures

| File | Paper figure | What it shows |
|---|---|---|
| `Figure_2_preprocessing.png` | Figure 2 | Dataset preprocessing: pKd density by split (train, val, test), protein length vs the 1024-residue limit, and SMILES token length vs the 256-token limit |
| `Figure_5_attention_fusion.png` | Figure 5 | Pocket-aware attention fusion |
| `Figure_11_Actual_vs_Predicted.png` | Figure 11 | Predicted vs experimental pKd for validation (n = 1005), test (n = 1005), and CASF-2016, with identity line and linear fit |
| `Figure_12_Prediction_Error_Distribution.png` | Figure 12 | Signed error (predicted − experimental) histogram on the test set, with mean and median marked |
